# Contributing a land or side quest

1. Read [docs/PACK_GUIDE.md](docs/PACK_GUIDE.md) and copy [docs/pack-template.json](docs/pack-template.json).
2. Test it in the game: **MODS** → paste → **VALIDATE** → **INSTALL** → **PLAY**.
3. Add it as `community/<your-id>.json` and open a pull request.
4. The automatic check must pass (you can run `node tools/validate.js community/<your-id>.json` locally).

Please keep packs family-friendly and original: no copyrighted characters or text.
